    Maximise LLM prompt-cache hits¶

    Reorder the columns of a table so that serialized rows share a longer prefix and more of every prompt is served from the LLM's cache. A model rewrites a published ordering algorithm; a fixed grader measures it on five real tables. Meta-Evolve gives the model six rewrites and keeps the best score.

    Meta-Evolve can improve anything you can seed, rewrite, and score: source code, prompts, configurations, or schemas. Here, the artifact is a Python module.

    Status: Experimental/live-only.

    Open the self-contained Jupyter notebook

    Run the notebook in order, or copy the cells below into a new one. The grader is folded away; expand it when copying. No checkout or separate helper files are needed.

    Set up¶

    Use a Python 3.12+ Jupyter kernel. Set OPENROUTER_API_KEY for the model calls; scoring the seed needs no key. Install the dependencies:

    %pip install -q "pandas>=2.1" networkx "meta-evolve @ git+https://github.com/sentient-xyz/meta-evolve.git"

    Rows of a table are serialized left to right and sent to an LLM. A row prefix that already appeared is served from the prompt cache, so column order decides how much you pay. Put the columns the rows agree on first, and the shared text is a prefix:

    col 1 col 2 col 3 col 4 col 5
    row n Just Mercy Drama Warner Bros. Fresh True
    row n+1 Just Mercy Drama Warner Bros. Rotten False

    Both rows share Just Mercy, Drama, Warner Bros. — a cache hit. The algorithm may reorder columns and rows. It may not change a cell.

    Components of the loop¶

    1. Fetch the seed algorithm¶

    The seed is GRG, the published algorithm from the ADRS llm_sql task. This cell downloads it and loads it as a Python source string — the artifact Meta-Evolve rewrites.

    import subprocess
from pathlib import Path

import meta_evolve as meta

WORK = Path("adrs_llm_sql_run").resolve()
TASK = WORK / "adrs-upstream" / "openevolve" / "examples" / "ADRS" / "llm_sql"
WORK.mkdir(parents=True, exist_ok=True)

if not TASK.exists():
    subprocess.run(
        ["git", "clone", "--filter=blob:none", "--no-checkout",
         "https://github.com/UCB-ADRS/ADRS.git", str(WORK / "adrs-upstream")],
        check=True,
    )
    subprocess.run(
        ["git", "sparse-checkout", "set", "openevolve/examples/ADRS/llm_sql"],
        cwd=WORK / "adrs-upstream", check=True,
    )
    subprocess.run(["git", "checkout"], cwd=WORK / "adrs-upstream", check=True)

SEED = (TASK / "initial_program.py").read_text()

    2. Score a candidate¶

    The grader reorders five tables with the candidate and returns one number:

    combined_score = 0.95 * mean(hit_rate) + 0.05 * (12 - min(12, mean(runtime))) / 12

    Hit rate carries most of the weight; runtime is a tiebreaker. The evaluator runs the grader in a subprocess, so a hang cannot take the notebook with it. Run this cell before setting an API key: a hit rate of about 0.713 means the setup works.

    import json, os, subprocess, sys
from pathlib import Path
from urllib.request import urlretrieve

GRADER = Path("score_one.py")
if not GRADER.exists():
    urlretrieve(
        "https://sentient-xyz.github.io/meta-evolve-docs/applications/llm-sql/score_one.py",
        GRADER,
    )

def evaluate(source):
    """Score one Evolved module. Returns combined_score, or raises on failure."""
    work = WORK / "candidates"
    work.mkdir(parents=True, exist_ok=True)
    program = work / "candidate.py"
    program.write_text(str(source))
    done = subprocess.run(
        [sys.executable, str(GRADER.resolve()), str(program)],
        cwd=str(WORK),
        env={**os.environ, "ADRS_TASK_DIR": str(TASK)},
        capture_output=True, text=True, timeout=900,
    )
    report = None
    for line in reversed(done.stdout.splitlines()):
        if line.strip().startswith("{"):
            report = json.loads(line.strip())
            break
    if not report or not report.get("ok"):
        raise RuntimeError((report or {}).get("error") or done.stderr[-500:] or "score failed")
    print(f"hit rate {report['average_hit_rate']:.4f} · "
          f"runtime {report['average_runtime']:.1f}s · "
          f"combined {report['combined_score']:.4f}")
    return report["combined_score"]

evaluate(SEED)
# Output:
# hit rate 0.7129 · runtime 7.5s · combined 0.6961
    Copy the grader (required for a new notebook)

    score_one.py loads class Evolved, reorders the five ADRS tables, rejects a candidate that drops rows or shrinks the serialized text by more than 1%, and prints one JSON object. The model rewrites Evolved, never the grader.

    """Score one Evolved program on ADRS llm_sql. Prints one JSON object to stdout."""
from __future__ import annotations

import importlib.util
import json
import os
import sys
import time
import traceback

PROGRAM_PATH = os.path.abspath(sys.argv[1])
TASK_DIR = os.environ["ADRS_TASK_DIR"]
sys.path.insert(0, TASK_DIR)
os.chdir(TASK_DIR)

import pandas as pd  # noqa: E402
from utils import evaluate_df_prefix_hit_cnt  # noqa: E402

TEST_FILES = [
    "datasets/movies.csv",
    "datasets/beer.csv",
    "datasets/BIRD.csv",
    "datasets/PDMX.csv",
    "datasets/products.csv",
]
COL_MERGES = [
    [["movieinfo", "movietitle", "rottentomatoeslink"]],
    [["beer/beerId", "beer/name"]],
    [["PostId", "Body"]],
    [
        ["path", "metadata"],
        ["hasmetadata", "isofficial", "isuserpublisher", "isdraft", "hasannotations", "subsetall"],
    ],
    [["product_title", "parent_asin"]],
]
REORDER_KWARGS = dict(
    early_stop=100000, distinct_value_threshold=0.7, row_stop=4, col_stop=2
)
MAX_CHAR_SHRINK = 0.01


def total_chars(frame):
    return int(frame.astype(str).map(len).to_numpy().sum())


def load_evolved(path):
    spec = importlib.util.spec_from_file_location("candidate_program", path)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module.Evolved


def main() -> int:
    try:
        evolved = load_evolved(PROGRAM_PATH)
    except Exception as error:
        print(json.dumps({"ok": False, "stage": "import", "error": f"{type(error).__name__}: {error}"}))
        return 0

    per_dataset = []
    for filename, col_merge in zip(TEST_FILES, COL_MERGES):
        frame = pd.read_csv(filename)
        before_chars = total_chars(frame)
        before_rows = len(frame)
        try:
            start = time.time()
            reordered, _ = evolved().reorder(frame, col_merge=col_merge, **REORDER_KWARGS)
            runtime = time.time() - start
        except Exception as error:
            print(json.dumps({
                "ok": False, "stage": "run", "dataset": filename,
                "error": f"{type(error).__name__}: {error}",
                "traceback": traceback.format_exc(),
            }))
            return 0
        after_chars = total_chars(reordered)
        if len(reordered) != before_rows:
            print(json.dumps({"ok": False, "stage": "invalid", "error": "row count changed"}))
            return 0
        shrink = (before_chars - after_chars) / before_chars if before_chars else 0.0
        if shrink > MAX_CHAR_SHRINK:
            print(json.dumps({
                "ok": False, "stage": "invalid",
                "error": f"serialized text shrank by {shrink * 100:.2f}%",
            }))
            return 0
        hit_count, hit_pct = evaluate_df_prefix_hit_cnt(reordered)
        per_dataset.append({
            "dataset": os.path.basename(filename),
            "hit_rate": hit_pct / 100.0,
            "runtime": runtime,
            "hit_count": hit_count,
        })

    hit_rates = [row["hit_rate"] for row in per_dataset]
    runtimes = [row["runtime"] for row in per_dataset]
    average_hit_rate = sum(hit_rates) / len(hit_rates)
    average_runtime = sum(runtimes) / len(runtimes)
    combined = 0.95 * average_hit_rate + 0.05 * (12 - min(12, average_runtime)) / 12
    print(json.dumps({
        "ok": True,
        "combined_score": combined,
        "average_hit_rate": average_hit_rate,
        "average_runtime": average_runtime,
        "per_dataset": per_dataset,
    }))
    return 0


if __name__ == "__main__":
    sys.exit(main())

    3. Propose a rewrite¶

    The proposer is an ordinary function: source in, source out. It sends the current best program to z-ai/glm-5.3-flash through OpenRouter and returns the rewritten module. The system prompt states the reorder signature the grader expects.

    import json, os, re, urllib.request

API_KEY = os.environ["OPENROUTER_API_KEY"]
MODEL = "z-ai/glm-5.3-flash"
SYSTEM = """You evolve a Python algorithm for the ADRS llm_sql task.
Reorder columns and rows only. Never change a cell.
Emit one module that defines class Evolved(Algorithm) with:
    def reorder(self, df, early_stop=0, row_stop=None, col_stop=None,
                col_merge=[], one_way_dep=[], distinct_value_threshold=0.8,
                parallel=True)
reorder must return a (DataFrame, list) tuple.
Import the base class with `from solver import Algorithm`.
Return only a ```python block."""

def propose(parent):
    payload = json.dumps({
        "model": MODEL,
        "temperature": 0,
        "seed": 0,
        "messages": [
            {"role": "system", "content": SYSTEM},
            {"role": "user", "content": "Improve this Evolved algorithm.\n\n```python\n" + str(parent) + "\n```"},
        ],
    }).encode()
    request = urllib.request.Request(
        "https://openrouter.ai/api/v1/chat/completions",
        data=payload,
        headers={"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"},
        method="POST",
    )
    with urllib.request.urlopen(request, timeout=900) as response:
        body = json.load(response)
    text = body["choices"][0]["message"]["content"]
    blocks = re.findall(r"```(?:python)?\s*\n(.*?)```", text, re.DOTALL)
    source = max(blocks, key=len).strip() if blocks else text
    if "class Evolved" not in source:
        raise RuntimeError("model did not return class Evolved")
    return source

    4. Try six rewrites¶

    meta.improve scores the seed, then runs six rewrites with Greedy search. A higher score becomes the next parent; a lower score keeps the earlier best. random_seed=0 fixes Meta-Evolve's choices.

    result = meta.improve(
    seed=SEED,
    proposer=propose,
    evaluator=evaluate,
    trials=6,
    random_seed=0,
)

    A complete run makes six model calls and seven scoring passes. Expect a long run and real model usage. result.best().value gives you the selected source.

    for number, attempt in enumerate(result.trials()):
    score = attempt.metrics.get("score")
    label = f"{score:.4f}" if isinstance(score, (int, float)) else str(attempt.state)
    print(f"trial {number}: {label}")

print(f"\nselected: {len(str(result.best().value))} chars")
# Output:
# trial 0: 0.6961
# trial 1: 0.7070
# trial 2: 0.7166
# trial 3: 0.7166
# trial 4: 0.7169
# trial 5: 0.7168
# trial 6: 0.7171
#
# selected: 26113 chars

    These are all seven results from the live run of the cells above, with the grader's actual hit rates and scores. Trial 6 was selected. A new run may produce different programs and scores.

    Iteration Hit rate Runtime Score Greedy decision
    Seed (GRG) 0.7129 7.48 s 0.6961 Starting program
    Trial 1 0.6925 0.21 s 0.7070 Becomes the best
    Trial 2 0.7029 0.27 s 0.7166 Becomes the best
    Trial 3 0.7029 0.27 s 0.7166 Becomes the best

    Read the columns separately. The score rose from 0.6961 to 0.7171, but the hit rate fell from 0.7129 to 0.7032. The selected program moves the reordering onto numpy arrays and is 34 times faster than the seed, and under this grader that speed was worth more than the cache hits it gave up:

    Part of the score Seed → Trial 6 Change
    0.95 × hit rate 0.7129 → 0.7032 −0.0092
    0.05 × runtime term 7.48 s → 0.22 s +0.0303

    The run used 488,761 reported tokens. Scores reflect this grader's five tables and one hit-rate definition, not a measured saving on a live LLM API. Hit-rate differences below 0.001 are within the grader's precision.

    Try your own table¶

    Each part of the loop can be changed on its own. Keep score_one.py fixed during a run so every candidate faces the same grader.

    Change How Learn more
    Model Set MODEL in the proposer cell —
    Number of rewrites Set trials —
    Search method Pass search= to meta.run Choose what to try next
    Feedback to the model Return per-table results as evidence Give the proposer feedback
    What counts as better Set the task's objective Programming model
    The proposer itself Use an agent harness instead of one prompt Feedback Descent

    Model and trials. Any OpenRouter model works in MODEL. For another provider, change the URL, key, and model together. Raise trials for a longer search.

    Search method. meta.improve always uses Greedy. To choose another, declare the run as a meta.Experiment and pass search=:

    from dataclasses import replace

experiment = meta.Experiment(
    seed=SEED,
    proposer=propose,
    task=meta.Task(evaluator=evaluate),
    search=meta.Greedy(max_trials=6),
    random_seed=0,
)
greedy = meta.run(experiment)
population = meta.run(replace(experiment, search=meta.Population(size=3, max_trials=6)))
    Search Each rewrite starts from Good for
    meta.Greedy The best program so far Building on each improvement
    meta.BestOfN The seed, every time Independent attempts from one start
    meta.Population A tournament among the top few programs Keeping several ideas alive

    Feedback to the model. Here the model sees only the program. The grader already measures every table, so the evaluator can pass those results on, and the proposer can tell the model which tables to work on. Return an EvaluationResult with the results as evidence:

    def evaluate(source):
    ...  # score as before, then:
    tables = ", ".join(f"{t['dataset']} {t['hit_rate']:.3f}" for t in report["per_dataset"])
    return meta.EvaluationResult(
        metrics={"score": report["combined_score"], "hit_rate": report["average_hit_rate"]},
        evidence=(meta.EvidenceDraft(kind="per_table", data={"hit_rates": tables}),),
    )

    Then read it in the proposer and add it to the prompt:

    def propose(parent, *, context):
    feedback = context.evidence.latest("per_table").data["hit_rates"]
    # Add f"Hit rate per table: {feedback}" to the user message.
    ...

    Pass context=meta.RecentAncestors() to meta.improve or meta.Experiment so the proposer receives the selected program's latest evidence. The proposer would see a line such as Hit rate per table: movies.csv 0.794, beer.csv 0.707, BIRD.csv 0.822, PDMX.csv 0.398, products.csv 0.843.

    What counts as better. The recorded run maximised the combined score, which rewards speed as well as cache hits. Once the evaluator returns hit_rate as a metric, make it the objective to search for cache hits alone:

    task = meta.Task(evaluator=evaluate, objectives=(meta.Maximize(metric="hit_rate"),))

    An agent harness instead of a prompt. The proposer here sends one prompt and reads one reply. It can run a coding agent instead: give the agent a workspace with the current program, let it read, edit, and run code, and return the new source. The Feedback Descent example's ask helper runs a Codex agent this way. Any function that takes a program and returns a new one plugs into the same loop. When the artifact spans several files, use meta.SourceTree with meta.PatchProposer, which applies the agent's edits in a private workspace; see Improve a real file.

    Another algorithm. Replace the seed, the proposer prompt, and the grader. The propose → score → select loop stays the same. See the programming model for the callable contract.
