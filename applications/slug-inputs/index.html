    Find a slug-generation defect¶

    Search for an input that violates a function's guarantees, then retain the input, observed output, and lineage as a reproducible finding. Adapt the target function, input contract, and proposer to investigate another implementation.

    Status: Shipped. This offline fixture searches for a failing input to a real function in the repository. It uses no SDK, network requests, or credentials.

    The concrete problem¶

    A URL generator maps titles to lowercase slugs. It promises never to emit two consecutive dashes, but its single .replace("--", "-") pass mishandles three adjacent separators: "a---b" becomes "a--b".

    Here the candidate is the input, stored as one JSON string in input.json. The system under test, slugs.py, stays fixed. The deliverable is a reproducible bug report, not repaired source.

    The input contract accepts 1–80 printable ASCII characters. For those inputs, the output must contain only lowercase letters, digits, and dashes; have no leading, trailing, or consecutive dashes; and be 1–80 characters long.

    Setup and run¶

    Use Python 3.12+, Git, and uv:

    git clone https://github.com/sentient-xyz/meta-evolve.git
cd meta-evolve
uv sync --locked

    From that repository root, run the maintained fixture:

    uv run python examples/domains/adversarial_inputs/main.py
    Output
    defect found after 2 evaluations
  input:  'a---b'
  output: 'a--b'
  broke:  guarantee 3: the slug contains two '-' in a row
  repro:  slugify('a---b')
lineage, from a benign seed to the input that breaks it:
  step 0: 'Hello, World' defect=0.0
  step 1: 'a---b' defect=1.0

    The seed is evaluated before the one successful revision. The result retains the candidate and its ancestry, so the report identifies the exact failing input. The fixture already knows that input; this is not measured model discovery.

    Declare the search¶

    This function is extracted from the maintained main.py. Its helper definitions and input data are explained here and included below.

    main.py · hunt_for_defects
    def hunt_for_defects(
    build_agent: Callable[[str], Proposer],
    *,
    random_seed: int = 0,
) -> meta.Run:
    """Search for an input that breaks slugify, starting from a benign one."""

    experiment = meta.Experiment(
        task=defect_task(),
        seed=meta.load_source_tree(SEED),
        proposer=build_agent(INSTRUCTIONS),
        # `BestOfN`, not `Greedy`: a binary "did it break" gives a hill-climber
        # no hill, so a greedy incumbent would never leave the seed anyway.
        # This names what the search really is -- N independent probes from one
        # benign seed, stopping the moment one lands.
        search=meta.BestOfN(max_trials=MAX_ATTEMPTS),
        # No context policy, deliberately: the record committed for an artifact
        # is its identity, not its content, so a policy could say an earlier
        # attempt scored 0.0 but never which input scored it. The README says
        # why that trade is not worth thousands of characters of event JSON.
        random_seed=random_seed,
    )
    return meta.run(experiment)
    Component What it does here
    Artifact / seed SourceTree containing input.json, initially "Hello, World"
    Proposer fixture_agent(INSTRUCTIONS) returns a callable that writes JSON "a---b"
    Evaluator score_candidate validates the input, calls the fixed slugify, then checks its guarantees
    Objective Maximize defect; a confirmed in-contract failure scores 1.0 and satisfies the task
    Search BestOfN, up to three independent probes from the seed and four evaluations
    Feedback No context policy; the fixture does not learn from prior probes
    Fixed controls Input contract, target function, grader, instruction brief, and work limits

    build_agent is the caller-supplied factory; main() passes fixture_agent. A real wrapper can occupy that same position. Its instructions describe the input contract and promises; the candidate tree does not contain slugs.py.

    Read findings and failures correctly¶

    A readable input outside the contract scores 0.0: it cannot establish a broken promise. A valid in-contract input that violates a guarantee, or crashes the target function, scores 1.0. An unreadable input.json records InvalidOutput without a score. These outcomes distinguish a finding from a malformed probe.

    A run with no finding reports how many attempts were judged. It does not prove there are no bugs. No untouched data split or fuzzing-coverage guarantee is provided. The fixed fixture demonstrates this defect and the reporting boundary. The command keeps its run in memory; retained lineage alone is not a disk backup.

    Change and predict¶

    In a scratch checkout, change the JSON string written by fixture_agent from "a---b" to "a-b" and rerun the command. Predict no defect: all three probes are judged and score 0.0. There are four evaluations including the seed, and the report explicitly limits its claim to the inputs judged. Restore the fixture.

    To adapt the hunt, replace the target, input contract, and guarantee checks in slugs.py, then supply a proposer through hunt_for_defects. Keep the grader outside candidate control. The evaluator must decide what counts as an actual violation of the new function's contract.

    Complete supporting source¶

    The seed file contains exactly "Hello, World" as a JSON string.

    main.py 
    """Evolve an input that breaks the system under test.

Every other example evolves a *solution*. This one evolves a *problem*: the
artifact is an input, the objective is inverted, and the winning lineage is a
bug report. The system under test is ``slugs.slugify`` — a few lines of
ordinary application code in this directory, with a defect of the kind that
passes review and ships. The proposer is told the contract and the promises
and never sees the source, so it probes a black box — which is what makes a
find a find. The evaluator needs no model at all: it calls the function and
checks whether it kept its word.

The hard part is not maximizing failure. It is refusing to be satisfied by the
wrong failures. A naive "break it" reward converges on the empty string, a
megabyte of junk, or a lone surrogate — inputs ``slugify`` never promised
anything about, so mangling them proves nothing and fixing them is not work.
So the evaluator gates on the *documented contract* before it judges anything:
an input outside the contract scores ``0.0`` however badly it comes out, and
only an in-contract input that breaks a stated guarantee scores ``1.0``. The
README works through why that gate is the whole design, and what it costs.

Every piece is importable and injectable: ``hunt_for_defects`` takes the
proposer factory. The shipped ``fixture_agent`` is a deterministic stand-in,
so ``main()`` and the tests run offline with no credential and no live call;
a wrapper around any model SDK drops into the same argument — the user-owned
boundary that ``docs/guides/providers.md`` documents.
"""

from __future__ import annotations

import json
import sys
from collections.abc import Callable
from pathlib import Path

import meta_evolve as meta
from meta_evolve.domain import InvalidOutput
from meta_evolve.ports import EvaluationResult, EvidenceDraft, Proposer

HERE = Path(__file__).resolve().parent
if str(HERE) not in sys.path:
    # What running this file as a script already does, so it finds its sibling
    # however it was loaded.
    sys.path.insert(0, str(HERE))

import slugs  # noqa: E402 — needs the path entry above


SEED = HERE / "seed"
INPUT_FILE = "input.json"
FOUND = 1.0

# Per-attempt bounds for a session-based wrapper to enforce on itself,
# declared rather than inherited: the timeout sizes the run's wall ceiling
# below, and the turn cap is the headroom a one-edit session needs. The
# shipped fixture spends neither, which is why they stay: they belong to the
# brief a real wrapper inherits, not to the fixture.
AGENT_TIMEOUT_SECONDS = 120.0
ATTEMPT_TURNS = 12
# One proposer session per attempt; the run stops the moment one lands. The
# wall ceiling covers every attempt's timeout; the evaluator costs nothing.
MAX_ATTEMPTS = 3
BUDGET = meta.Budget(
    evaluations=MAX_ATTEMPTS + 1,
    trials=MAX_ATTEMPTS,
    wall_seconds=AGENT_TIMEOUT_SECONDS * (MAX_ATTEMPTS + 1),
)

# The agent is handed the contract and the promises, exactly as a caller of
# slugify would read them, and nothing else. It never sees slugs.py, so it is
# probing a black box — which is what makes a find a find.
INSTRUCTIONS = (
    f"{INPUT_FILE} holds one JSON string. That string is passed to slugify(), "
    "a function you cannot see, which turns a human-written title into a URL "
    "slug. The title already in the file is one slugify handles correctly, so "
    "it is worth nothing; replace it.\n\n"
    "Find a title that makes slugify break one of its own documented "
    "promises.\n\n"
    "The contract you must stay inside. A title outside it proves nothing "
    "about slugify and scores nothing, however badly it comes out:\n"
    "- a string of 1 to 80 characters\n"
    "- every character printable ASCII, U+0020 through U+007E\n\n"
    "What slugify promises for every title inside that contract:\n"
    "1. the slug contains only lowercase letters, digits, and '-'\n"
    "2. the slug neither starts nor ends with '-'\n"
    "3. the slug never contains two '-' in a row\n"
    "4. the slug is between 1 and 80 characters long\n\n"
    f"Edit {INPUT_FILE} so it holds one JSON string that keeps the contract "
    f"and makes one of those four promises false. Change only {INPUT_FILE}.\n\n"
    # For cost, not for turns: ATTEMPT_TURNS leaves a session ample headroom,
    # so holding to one act is a spending choice rather than a workaround for
    # a limit it is about to hit.
    "Everything you need is above. Write the file in a single edit and end "
    "the session. Do not list files, re-read your edit, or verify it."
)


def read_input(tree: meta.SourceTree) -> str:
    """The one candidate input, decoded, or a ``ValueError`` saying why not.

    A JSON string rather than raw file bytes, because it is exact — a trailing
    space or a leading newline can be written and meant, with no stripping
    convention to argue over — and because it is safe: a lone surrogate rides
    as a plain-ASCII ``\\u`` escape, so the artifact stays valid UTF-8 even
    when the input it encodes does not. The README works through both.
    """

    try:
        source = tree[INPUT_FILE]
    except KeyError:
        raise ValueError(f"the candidate has no {INPUT_FILE}") from None
    try:
        value = json.loads(source)
    except json.JSONDecodeError as error:
        raise ValueError(f"{INPUT_FILE} is not valid JSON: {error}") from None
    if not isinstance(value, str):
        raise ValueError(
            f"{INPUT_FILE} must hold one JSON string, not {type(value).__name__}"
        )
    return value


def score_candidate(tree: meta.SourceTree) -> EvaluationResult:
    """Did this input break slugify? ``1.0`` if it did, ``0.0`` if it did not.

    Three outcomes, and keeping them apart is the entire design:

    * no readable input at all — a typed ``InvalidOutput`` carrying no metric.
      This is not a boring failure to break slugify; it is a proposal the
      evaluator cannot judge. Scoring it ``0.0`` would let the search read
      "unreadable" as "harmless" and quietly stop looking there.
    * a readable input outside the documented contract — ``0.0``. Judged, and
      not a finding. slugify promised nothing about it, so whatever it does
      with it says nothing about slugify.
    * a readable in-contract input that breaks a stated guarantee — ``1.0``.
      A defect, and the lineage that reached it is the report.
    """

    try:
        title = read_input(tree)
    except ValueError as error:
        return EvaluationResult(
            failure=InvalidOutput(message=str(error), details={"file": INPUT_FILE})
        )
    outside = slugs.contract_violation(title)
    if outside is not None:
        return _verdict(0.0, "outside the contract", outside)
    try:
        slug = slugs.slugify(title)
    except Exception as error:
        # An in-contract input that crashes the function is the strongest
        # finding there is, and it is emphatically not an evaluator fault: the
        # evaluator did its job and the answer is "it broke". Left to the
        # adapter this would surface as an EvaluatorFailure carrying no
        # metric, which would hide the best result the search can produce.
        return _verdict(FOUND, "raised", f"{type(error).__name__}: {error}")
    broken = slugs.guarantee_violation(slug)
    if broken is None:
        return _verdict(0.0, "kept every guarantee", slug)
    return _verdict(FOUND, "broke a guarantee", f"{slug!r}: {broken}")


def _verdict(defect: float, outcome: str, detail: str) -> EvaluationResult:
    """One score, and the diagnosis that produced it, recorded together."""

    return EvaluationResult(
        metrics={"defect": defect},
        evidence=(
            EvidenceDraft(
                kind="slugify.verdict",
                data={"outcome": outcome, "detail": detail},
            ),
        ),
    )


def defect_task() -> meta.Task:
    """Maximize failure, against the one metric that ranks."""

    return meta.Task(
        evaluator=score_candidate,
        artifact=meta.SourceTree,
        # One metric, inverted. "Did it break" has no gradient to climb -- an
        # input either is a finding or is not -- so `satisfy` stops the run the
        # moment one lands, rather than paying for attempts that cannot improve
        # on it.
        objectives=(meta.Maximize("defect", satisfy=FOUND),),
        budget=BUDGET,
    )


def hunt_for_defects(
    build_agent: Callable[[str], Proposer],
    *,
    random_seed: int = 0,
) -> meta.Run:
    """Search for an input that breaks slugify, starting from a benign one."""

    experiment = meta.Experiment(
        task=defect_task(),
        seed=meta.load_source_tree(SEED),
        proposer=build_agent(INSTRUCTIONS),
        # `BestOfN`, not `Greedy`: a binary "did it break" gives a hill-climber
        # no hill, so a greedy incumbent would never leave the seed anyway.
        # This names what the search really is -- N independent probes from one
        # benign seed, stopping the moment one lands.
        search=meta.BestOfN(max_trials=MAX_ATTEMPTS),
        # No context policy, deliberately: the record committed for an artifact
        # is its identity, not its content, so a policy could say an earlier
        # attempt scored 0.0 but never which input scored it. The README says
        # why that trade is not worth thousands of characters of event JSON.
        random_seed=random_seed,
    )
    return meta.run(experiment)


def bug_report(run: meta.Run) -> str:
    """The winning lineage, rendered as the thing it already is."""

    trial = run.best_trial()
    lineage = "\n".join(
        f"  step {step.logical_step}: {_step(step)}" for step in run.lineage()
    )
    if trial.metrics["defect"] != FOUND:
        # Not "slugify kept its promises": reporting coverage the run did
        # not buy is how a tool like this does real damage, and ``run.trials()``
        # makes the attempts nothing judged countable rather than hedged.
        attempts = run.trials()[1:]
        unjudged = [a for a in attempts if a.state != "evaluated"]
        kinds = sorted({a.failure.kind if a.failure else a.state for a in unjudged})
        note = f" ({', '.join(kinds)})" if kinds else ""
        return "\n".join(
            (
                f"no defect found: {len(attempts) - len(unjudged)} of "
                f"{len(attempts)} attempts judged{note}",
                "nothing that was judged broke a documented guarantee, which "
                "is not the same as saying there is nothing to find",
                lineage,
            )
        )
    title = read_input(trial.artifact.value)
    slug = slugs.slugify(title)
    return "\n".join(
        (
            f"defect found after {run.summary().evaluation_count} evaluations",
            f"  input:  {title!r}",
            f"  output: {slug!r}",
            f"  broke:  {slugs.guarantee_violation(slug)}",
            f"  repro:  slugify({title!r})",
            "lineage, from a benign seed to the input that breaks it:",
            lineage,
        )
    )


def _step(step: meta.TrialView) -> str:
    """One lineage entry: what was tried, and what it was worth."""

    score = step.metrics.get("defect")
    if score is None:
        # A step that was never scored is not a step that scored nothing. No
        # metric means the evaluation recorded a typed failure instead, and
        # `TrialView` carries it, so the report names it rather than inventing
        # a number for it.
        return f"unranked ({step.failure.kind})"
    return f"{read_input(step.artifact.value)!r} defect={score}"


def fixture_agent(_instructions: str) -> Proposer:
    """The shipped proposer: a deterministic fixture, not a model.

    It makes exactly the move a live agent session would — rewrite
    ``input.json``, touch nothing else — but always proposes ``"a---b"``:
    the smallest in-contract title with three non-alphanumerics in a row,
    which is the shape the repeated-dash defect needs. That keeps ``main()``
    credential-free, offline, and its transcript reproducible.

    It ignores its instructions on purpose; the brief exists for proposers
    that can read it. To run the hunt against a real model, wrap its SDK in
    a callable of this same shape — ``(SourceTree, context) -> SourceTree``
    — and hand the factory to ``hunt_for_defects``. The evaluator, the gate,
    the budget, and the report do not change.
    """

    def propose(tree: meta.SourceTree, *, context) -> meta.SourceTree:
        return meta.SourceTree({**tree, INPUT_FILE: json.dumps("a---b") + "\n"})

    return propose


def main() -> None:
    """Hunt with the shipped fixture and print the bug report.

    Deterministic and free: the fixture lands on its first attempt, so the
    run stops at two evaluations. A factory wrapping a real SDK in the same
    seat pays for at most MAX_ATTEMPTS == 3 proposer sessions.
    """

    result = hunt_for_defects(fixture_agent)
    try:
        print(bug_report(result))
    except meta.NoSuccessfulEvaluation:
        # Not "nothing broke": nothing was judged at all. Every evaluation
        # recorded a typed failure carrying no metric -- an input.json that
        # cannot be read is the likely one -- so there is no "no defect found"
        # to report either, and saying so would be a lie about coverage.
        print("no candidate was judged: every evaluation failed before scoring")
        print(f"run {result.id.value} recorded why; slugs.py is untouched")
        raise SystemExit(1)


if __name__ == "__main__":
    main()
    slugs.py 
    """The system under test: a slug generator, its contract, and its promises.

``slugify`` turns a human-written title into a URL slug. It is ordinary
application code — the kind that gets a handful of unit tests, passes review,
and ships. It has a defect. Finding it is what ``main.py`` searches for.

Three things live in this file, and keeping them apart is what makes that
search mean anything:

* ``contract_violation`` states what a *caller* owes ``slugify``. A title
  outside the contract is not ``slugify``'s problem, so a title outside the
  contract that comes back mangled is not a defect — however spectacular it
  looks.
* ``slugify`` is the code under test, defect and all.
* ``guarantee_violation`` states what ``slugify`` owes every caller who kept
  the contract. A guarantee broken on an in-contract title is a defect, full
  stop, and there is no arguing with it.

Both predicates are written from the prose below them, never from the
implementation. That is the whole point: derived from the code, they would
agree with it by construction and could never catch it being wrong.
"""

from __future__ import annotations


MAX_LENGTH = 80
SLUG_CHARACTERS = frozenset("abcdefghijklmnopqrstuvwxyz0123456789-")
FALLBACK = "untitled"


def contract_violation(title: object) -> str | None:
    """Why ``title`` is outside the documented contract, or ``None``.

    The contract, stated once and enforced here: a title is a string of 1 to
    80 characters, every one of them printable ASCII (U+0020 through U+007E).
    Callers normalize before calling. That is a real obligation, not a polite
    suggestion — a caller that ignores it is owed nothing below.
    """

    if not isinstance(title, str):
        return f"a title must be a string, not {type(title).__name__}"
    if not title:
        return "a title must not be empty"
    if len(title) > MAX_LENGTH:
        return f"a title must be at most {MAX_LENGTH} characters, not {len(title)}"
    for position, character in enumerate(title):
        if not 0x20 <= ord(character) <= 0x7E:
            return (
                f"character {position} (U+{ord(character):04X}) "
                "is not printable ASCII"
            )
    return None


def slugify(title: str) -> str:
    """Return a URL slug for ``title``.

    Guaranteed for every title inside the contract above:

    1. the slug contains only lowercase letters, digits, and ``-``;
    2. the slug neither starts nor ends with ``-``;
    3. the slug never contains two ``-`` in a row;
    4. the slug is between 1 and 80 characters long.
    """

    dashed = "".join(
        character if character.isalnum() else "-" for character in title.lower()
    )
    return dashed.replace("--", "-").strip("-") or FALLBACK


def guarantee_violation(slug: object) -> str | None:
    """Which of ``slugify``'s four guarantees ``slug`` breaks, or ``None``."""

    if not isinstance(slug, str):
        return f"a slug must be a string, not {type(slug).__name__}"
    stray = "".join(
        sorted({character for character in slug if character not in SLUG_CHARACTERS})
    )
    if stray:
        return f"guarantee 1: the slug contains {stray!r}"
    if slug.startswith("-") or slug.endswith("-"):
        return "guarantee 2: the slug starts or ends with '-'"
    if "--" in slug:
        return "guarantee 3: the slug contains two '-' in a row"
    if not 1 <= len(slug) <= MAX_LENGTH:
        return f"guarantee 4: the slug is {len(slug)} characters long"
    return None
