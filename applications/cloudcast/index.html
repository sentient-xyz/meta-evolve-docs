    Broadcast data across clouds¶

    Copy a 300 GB object from one cloud region to six or seven others as cheaply as possible. A coding agent rewrites a naive routing function, a fixed grader prices its routes, and Meta-Evolve keeps the best of ten attempts.

    Result: on 8 unseen jobs, the selected program costs 39.2% less than the seed. The ADRS paper reports 31.1% against the same seed.

    Status: Experimental/live-only. Open the notebook or copy the cells below into a new one.

    Set up¶

    You need Python 3.12+ and Docker running. The agent also needs the OpenCode CLI and OPENROUTER_API_KEY. This cell installs the dependencies and downloads the task (cloudcast.py) and the agent (opencode_agent.py). On first use, cloudcast.py fetches the released link prices and jobs from ADRS.

    %pip install -q networkx==3.6.1 "meta-evolve @ git+https://github.com/sentient-xyz/meta-evolve.git@69354f9ebb66df37e5bfc78c26aecff2d1d78fae"

from urllib.request import urlretrieve

BASE = "https://sentient-xyz.github.io/meta-evolve-docs/applications/cloudcast/"
for name in ["cloudcast.py", "opencode_agent.py"]:
    urlretrieve(BASE + name, name)

    What is scored. A program returns the route each of the object's 10 pieces takes to each destination. Each link costs its egress price per piece crossing it, and each region on the routes rents VMs for the transfer. total_cost sums this over five jobs; lower is better. A shared link is paid for once, so a shared tree beats separate copies.

    Components of the loop¶

    1. Load the seed¶

    The seed is the ADRS paper's starting program: a separate copy from the source to every destination.

    import meta_evolve as meta
from cloudcast import REFERENCES, SEED_SOURCE, DockerSandbox, evaluate

print(SEED_SOURCE)
# Output:

    2. Score a candidate¶

    Candidates run in a container with no network, host files or API key, and only report their routes. The grader checks every hop against the real graph and prices the routes itself, so a candidate cannot fake its cost. Scoring the seed and the two released baselines checks that Docker works:

    sandbox = DockerSandbox()

def score(source):
    return evaluate(source, sandbox=sandbox)

for name, source in REFERENCES.items():
    print(f"{name:<24} {score(source).metrics['total_cost']:.2f}")
# Output:
# direct_replication_seed  1199.17
# released_dijkstra        1045.86
# released_mdst            682.97

    3. Propose with a coding agent¶

    Each trial, an OpenCode agent (deepseek/deepseek-v4-flash-0731 via OpenRouter) sees the current program, its costs, and earlier trials. It edits the program and tests it with python agent_check.py, its only allowed command, for up to 10 steps.

    from opencode_agent import OpenCodeAgent

agent = OpenCodeAgent("cloudcast_run/agent", score)

    4. Try ten trials¶

    TreeSearch picks which program to improve next; BestSibling and PullAccess decide what the agent is told about earlier trials.

    from meta_evolve.policies import TreeSearch

experiment = meta.Experiment(
    task=meta.Task(
        evaluator=score,
        artifact=meta.Text,
        objectives=(meta.Minimize("total_cost"),),
        budget=meta.Budget(trials=10, spend_micros=1_000_000),  # stop at 10 trials or $1
    ),
    seed=meta.Text(SEED_SOURCE),
    proposer=agent,
    search=TreeSearch(max_trials=10),
    context=meta.BestSibling(max_records=40, max_chars=60_000),
    experience=meta.PullAccess(max_operations=1, max_results=40, max_records=60, max_chars=120_000),
    random_seed=20260922,
)
result = meta.run(experiment)

for trial in result.trials():
    cost = trial.metrics.get("total_cost")
    print(f"trial {trial.logical_step}: " + (f"{cost:.2f}" if cost is not None else trial.failure.kind))
# Output:
# trial 0: 1199.17
# trial 1: 712.46
# trial 2: 711.08
# trial 3: 711.49
# trial 4: 711.08
# trial 5: 830.20
# trial 6: 711.08
# trial 7: 711.08
# trial 8: 674.24
# trial 9: 667.81
# trial 10: 711.08

    5. Check it on unseen jobs¶

    from cloudcast import held_out_jobs

unseen = held_out_jobs()
for name, source in {**REFERENCES, "meta_evolve": result.best().value}.items():
    print(f"{name:<24} {evaluate(source, sandbox=sandbox, jobs=unseen).metrics['total_cost']:.2f}")
# Output:
# direct_replication_seed  1431.36
# released_dijkstra        1416.72
# released_mdst            840.45
# meta_evolve              870.23

    The recorded run¶

    All ten trials produced valid programs; trial 9 was selected. The run cost about $0.07.

    Seed  1199.17    a separate copy to every destination
├── Trial 1   712.46   one shared tree over the destinations
│   ├── Trial 4   711.08
│   └── Trial 9   667.81   the tree plus a cheaper-reattachment pass   selected
├── Trial 2   711.08   the same kind of tree, built nearest-destination-first
│   ├── Trial 3   711.49
│   └── Trial 8   674.24   several trees, keep the cheapest, then reattach
├── Trial 5   830.20   a spanning tree over the destinations; a regression
│   ├── Trial 6   711.08
│   └── Trial 7   711.08
└── Trial 10  711.08

    Trial 9 beat the released MDST baseline on training (667.81 vs 682.97) but not on the unseen jobs (870.23 vs 840.45), because Meta-Evolve selects on training cost only. The paper's 31.1% comes from 100 OpenEvolve iterations on unreleased jobs, so compare reductions, not absolute costs.
