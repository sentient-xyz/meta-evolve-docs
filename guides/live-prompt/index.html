    Live SDK example: routing prompt¶

    For a first run, use the notebook learning path. This guide keeps the full live SDK, execution, accounting, and persistence example.

    Status: Experimental/live-only. The loop is tested offline with injected providers. No retained live transcript is available yet; no improvement is promised.

    A support inbox needs to send each ticket to billing, account, or technical support. The candidate is the instruction text, not the model's answer. A model proposes revised instructions. To measure them, a fixed response model routes tickets and Python compares its labels with independent expected answers.

    This lesson stands on its own. Download the three-file prompt bundle: prompt.py contains the loop, prompt_cases.py contains the policy and cases, and openai_client.py owns SDK requests and accounting. All three files are expandable at the end of this page.

    Define what correct means¶

    The initial prompt already states the intended policy correctly. Improvement means better measured adherence, not inventing a different routing policy:

    Routing policy and starting instructions
    POLICY = """Route each support ticket to exactly one team:
billing: charges, invoices, or refunds.
account: identity, access, or account changes.
technical: product malfunction.
For mixed requests, follow the explicitly requested primary action.
If no primary action resolves the tie, choose account before billing before technical.
Return only the lowercase label: billing, technical, or account."""
SEED = POLICY  # Start with the correct policy; improvement is not guaranteed.
    Ticket Expected label Reason
    “I was charged twice. Please refund the duplicate.” billing Requested refund
    “I lost my recovery codes.” account Restore access
    “The dashboard freezes.” technical Product malfunction
    “I cannot sign in, but my priority is a refund.” billing Explicit primary action wins
    “Reset my password and send my invoice.” account Unresolved tie: account precedes billing

    There are 40 fictional development tickets and 12 distinct final tickets. Final checks run once after selection and never enter search or feedback. The full case file is visible for review; separation does not make its contents secret.

    Assemble the improvement loop¶

    The proposer writes revised instructions using the selected parent's recorded observations. The evaluator asks the response model to follow those instructions and grades the answers. Search selects the next parent and decides when to stop. Feedback is explicitly authorized development evidence.

    Experiment and feedback · extracted from prompt.py
    def experiment(client, *, seed=SEED, trials=3):
    def propose(parent, *, context):
        latest = context.evidence.latest("routing-feedback")
        if latest is None:
            raise meta.CapabilityError("No routing feedback selected; check the evidence label and max_records.")
        if latest.data.get("prompt_sha256") != sha256(parent.encode()).hexdigest():
            raise meta.CapabilityError("Selected feedback is for another prompt; use RecentAncestors with enough records.")
        if context.evidence.truncated:
            print("Feedback: using the selected report; some context records or rendered text were truncated.")
        return client.generate(
            instructions=(
                "Rewrite the routing prompt to follow this policy. "
                "Return only the prompt.\n" + POLICY
            ),
            input=json.dumps({
                "prompt": parent, "development_checks": latest.data["checks"],
                "development_complete": latest.data["complete"],
                "development_failure": latest.data["failure"],
            }, default=dict),
        )

    return meta.Experiment(
        task=meta.Task(
            evaluator=lambda prompt: evaluate(prompt, client),
            objectives=(meta.Maximize("score", satisfy=1.0),),
            environment={"model": client.configuration, "lesson": lesson_identity()},
        ),
        seed=seed, proposer=propose, search=meta.Greedy(max_trials=trials),
        context=meta.RecentAncestors(max_records=200, max_chars=64_000),
    )

    POLICY and SEED are shown above. evaluate is shown below; lesson_identity fingerprints the implementation. The complete definitions are on this page. This is an extracted function, not an additional program to maintain.

    Role This experiment
    Artifact / seed The policy text in SEED; each proposed prompt is a new version
    Proposer propose asks client.generate for revised instructions
    Task / evaluator and objectives evaluate obtains ticket responses and grades their labels; maximize passing fraction, satisfying at 1.0
    Search Greedy, at most three revisions after the seed
    Feedback / experience RecentAncestors; context.evidence.latest("routing-feedback") reads a complete selected report
    External limits Fixed cases, expected labels, response-model configuration, request limits, attempt bound, and storage

    For one revision, Meta-Evolve selects the parent and supplies its authorized history. Your proposer sends that prompt and its development observations to the model. Your evaluator uses the replacement instructions for each ticket. Meta-Evolve records the responses, measurements, and usage, then selects the next parent. The candidate cannot change the answers, response-model configuration, feedback authorization, or attempt limit.

    The evaluator reserves routing-feedback for one report containing its checks, completion/failure state, and prompt digest. The proposer verifies that digest against its parent; the label alone proves neither authorship nor occurrence. Disabled context raises ContextDisabled. An enabled policy with a missing or different-parent report raises CapabilityError before any rewrite request. Increase the record allowance or fix the policy/report label, then start a new run.

    The truncation notice means records were omitted or rendered text was clipped. A retained structured report remains usable. max_chars does not trim its data or bound the SDK request; the fixed cases and request settings bound this lesson. Rejected siblings are outside the selected parent's ancestry. Keep Experiment here to record the SDK environment and accept budgets; the small callable path needs fewer declarations.

    Inspect the evaluator¶

    The model returns text; Python grades it. After stripping surrounding whitespace, only the exact expected lowercase label passes. There is no model judge. A wrong label is a measured failure. An unavailable response stops that evaluation with a typed failure and retained known usage, without a misleading partial score.

    Independent grading · extracted from prompt.py
    def feedback_report(prompt, checks, *, failure=None):
    """One evaluator-owned report, including partial observations after failure."""
    return meta.EvidenceDraft(kind="routing-feedback", data={
        "prompt_sha256": sha256(prompt.encode()).hexdigest() if isinstance(prompt, str) else None,
        "checks": [dict(check.data) for check in checks],
        "complete": failure is None,
        "failure": failure.kind if failure else None,
    })


def evaluate(prompt, client, *, cases=DEVELOPMENT):
    """Measure every ticket, or retain a typed failure without a partial score."""
    if not cases:
        raise ValueError("evaluation requires at least one ticket")
    if not isinstance(prompt, str) or not prompt.strip():
        failure = InvalidOutput(message="expected a nonempty prompt")
        return meta.EvaluationResult(
            failure=failure, evidence=(feedback_report(prompt, (), failure=failure),),
        )
    usage, evidence, checks = meta.Resources(), [], []
    for ticket, expected in cases:
        try:
            response = client.generate(instructions=prompt, input=ticket)
        except ExecutionAccountingUnknown as error:
            error.receipt = {
                "request": getattr(error, "receipt", None), "ticket": ticket,
                "completed_usage": asdict(usage),
                "completed_evidence": [evidence_record(item) for item in evidence],
            }
            raise
        usage += response.usage
        evidence.extend(response.evidence)
        if response.failure is not None:
            evidence.append(meta.EvidenceDraft(kind="routing-unavailable", data={
                "input": ticket, "expected": expected, "failure": response.failure.kind,
            }))
            evidence.append(feedback_report(prompt, checks, failure=response.failure))
            return meta.EvaluationResult(
                failure=response.failure, usage=usage, evidence=tuple(evidence),
            )
        check = meta.EvidenceDraft(kind="routing-case", data={
            "input": ticket, "expected": expected, "actual": response.candidate,
            "passed": response.candidate.strip() == expected,
        })
        checks.append(check)
        evidence.append(check)
    evidence.append(feedback_report(prompt, checks))
    return meta.EvaluationResult(
        metrics={"score": sum(check.data["passed"] for check in checks) / len(cases)},
        usage=usage, evidence=tuple(evidence),
    )

    cases defaults to the development set. evidence_record, included in the full script, serializes observations if accounting becomes unknown. Completed response evidence stays available even when a later ticket fails. Its final feedback report then contains only completed checks and a typed failure, allowing a failed seed to be revised without pretending the remaining tickets were measured.

    For expected billing, " billing\n".strip() passes; "Billing" and "billing because..." are completed wrong answers. Empty or incomplete model output with known tokens becomes InvalidOutput, without a score. A typed timeout or infrastructure failure from the provider boundary keeps its type. If request seven fails, the first six responses and all known usage survive; the remaining tickets are not silently marked wrong.

    Run with a model¶

    Install the SDK separately, set your own API key, and choose a new persistent directory:

    python -m pip install openai
export OPENAI_API_KEY="your-api-key"
python prompt.py --run ./runs/routing-01
# Calls the model for both rewriting and ticket responses; provider charges may apply.
# Prints measured attempts, response evidence, selected prompt, usage, and final check.
# Live scores and token counts vary; this is not a captured transcript.

    The default model is gpt-5.4-mini-2026-03-17; override it with OPENAI_MODEL. The shared wrapper uses the Responses API, a 120-second SDK request timeout, zero automatic retries, 4,096 output tokens, and reasoning effort none. The SDK timeout is not a hard total wall-clock deadline across network phases. Configuration stays fixed across candidates and is saved in configuration.json.

    The maximum is 163 development requests: 40 seed responses plus 3 × (1 rewrite + 40 responses). The separate final check adds 12 requests, for 175 total, without retries. Early satisfaction or failures can reduce that number. A perfect seed still needs 40 responses to establish its score and 12 final responses; it makes no rewrite request.

    Tokens are input plus output tokens; cached input is already included in input. Billed spend stays unknown unless an exact receipt is supplied. Estimates are evidence, not bills. A monetary ceiling stops further work when spend cannot be verified; it is not a provider-side hard spending cap. Missing token accounting after dispatch raises ExecutionAccountingUnknown and retains available receipts. The default has no monetary ceiling; its bound is the request count. A programmatic budget applies to development search, while final usage is separate.

    Understand the result¶

    The driver prints Seed, each revision, a representative ticket observation, and Best measured prompt. Read the actual label beside its expected label to understand a failed case. Inspect history/ for all retained observations. It also prints a captured RunSummary: baseline and selected measurement, proposals, evaluations (including the seed), typed failures, stop reason, usage, and saved-history location. The report is captured inside the storage block and rendered after it closes. New Run queries still need an open store.

    A tie keeps the earlier best occurrence. A regression stays in history and does not become the next parent. A score of 1.0 stops development early. The best prompt may therefore be the seed or an earlier revision. A final-check failure never triggers another rewrite, and final results do not alter development scores.

    Live results need evidence tied to code and configuration; one run does not establish generalization or guarantee the same answers on repetition.

    Keep the work¶

    run_lesson uses durable storage before selecting a prompt. Choose a new directory for each run; an existing directory is refused to avoid overwriting history.

    Saved item Meaning
    configuration.json Model, implementation fingerprint, Python version, attempts, and declared budget
    history/ and run-id.txt Committed versions, observations, decisions, usage, and run identity
    requests.jsonl Completed requests, responses, failures, evidence, and usage, including uncommitted calls
    selected.txt Best measured prompt, if one exists
    final.json Separate final measurements, responses, failure if any, and usage
    accounting-unknown.json Available receipts and interrupted phase when accounting is unknown

    Open a fresh terminal, activate the same environment, and inspect without a key:

    . .venv/bin/activate
python prompt.py --inspect ./runs/routing-01
# Reads retained attempts, responses, selected prompt, configuration, and final report.
# No model calls or new evaluations.

    Reopening does not resume the local callables or regenerate model responses. The driver uses meta.open_run(history_path, run_id=saved_id) and closes the owned handle on exit. Missing/corrupt stores and stale IDs keep typed errors. Without a saved ID, only a single run can be inferred; multiple IDs require explicit selection. Lexical ID order does not mean latest. See reopening for the standalone notebook form. If no candidate was successfully measured, there is no selected prompt and no final check. An accounting interruption leaves the committed prefix inspectable. Selecting a prompt does not deploy it.

    If accounting interrupts the seed, there may be no committed run or run ID yet; inspection still reads available reports. requests.jsonl has one JSON object per completed call, including rewrites. Read it to inspect every response without model calls. The journal and history overlap: do not add their usage totals together. An interruption during final checking preserves the selected prompt and development history. Load selected.txt as UTF-8 text to reuse its instructions in your own application.

    Change and predict¶

    In run_lesson, change the default trials=3 to trials=1 and run into a new directory. Predict the upper bound: 40 + (1 + 40) = 81 development requests, plus 12 final requests. The winner may stay the same; fewer attempts do not promise a different score. Keep policy, cases, and model settings fixed when comparing the two runs. Never use final tickets as rewrite feedback.

    Rehearse offline¶

    From a repository checkout, these tests replace only the provider while running the actual grader, search, accounting, and storage. No fixture is imported by the public lesson:

    python -m pip install pytest
python -m pytest -q tests/test_llm_prompt_lesson.py tests/test_llm_prompt_feedback.py tests/test_llm_prompt_persistence.py tests/test_llm_prompt_docs.py
# Offline verification; no API key or model requests required.

    These tests exercise improvement, ties, regressions, failures, and final-set separation with synthetic provider responses. Their scores and accounting are not a live transcript. Evidence and verification tracks live captures and independent review.

    Complete source¶

    Driver, evaluator, and experiment
    prompt.py
    """Improve a routing prompt with model responses and independent Python grading.

Run --dry-run without credentials. See docs/learn/llm-prompt.md for the lesson.
"""

import argparse
from dataclasses import asdict
from hashlib import sha256
import json
from pathlib import Path
import sys

import meta_evolve as meta
from meta_evolve.domain import InvalidOutput
from meta_evolve.errors import ExecutionAccountingUnknown

from prompt_cases import DEVELOPMENT, POLICY

SEED = POLICY  # Start with the correct policy; improvement is not guaranteed.

    })

def lesson_identity():
    root = Path(__file__).parent
    return {
        "sha256": sha256(b"".join((root / name).read_bytes() for name in
                                 ("prompt.py", "prompt_cases.py", "openai_client.py"))).hexdigest(),
        "python": sys.version,
    }


def evidence_record(item):
    return {"kind": item.kind, "data": dict(item.data)}


def save_json(path, value):
    path.write_text(json.dumps(value, indent=2, default=dict) + "\n", encoding="utf-8")


class RequestJournal:
    """Retain completed calls even if a later call prevents a history commit."""

    def __init__(self, client, path):
        self.client, self.path = client, path
        self.configuration = client.configuration

    def generate(self, *, instructions, input):
        result = self.client.generate(instructions=instructions, input=input)
        with self.path.open("a", encoding="utf-8") as journal:
            journal.write(json.dumps({
                "instructions": instructions, "input": input,
                "candidate": result.candidate,
                "failure": result.failure.kind if result.failure else None,
                "usage": asdict(result.usage),
                "evidence": [evidence_record(item) for item in result.evidence],
            }, default=dict) + "\n")
        return result


def show(result):
    for index, attempt in enumerate(result.trials()):
        outcome = attempt.failure.kind if attempt.failure else (
            f"{attempt.metrics['score']:.0%}" if attempt.metrics else "incomplete"
        )
        print(f"{'Seed' if index == 0 else 'Revision ' + str(index)}: {outcome}")
        checks = [item.data for item in attempt.evidence if item.kind == "routing-case"]
        if checks:
            row = next((row for row in checks if not row["passed"]), checks[0])
            print(f"  {row['input']!r} -> {row['actual']!r}; expected {row['expected']}")
    try:
        print("Best measured prompt:\n" + result.best().value)
    except meta.NoSuccessfulEvaluation:
        print("No successfully measured prompt.")
    return result.summary()  # Capture while storage is open; rendering needs no handle.


def run_lesson(client, directory, *, seed=SEED, trials=3, budget=None):
    """Save the selected prompt, then perform one final check outside search."""
    root = Path(directory)
    root.mkdir(parents=True, exist_ok=False)
    save_json(root / "configuration.json", {
        "model": client.configuration, "lesson": lesson_identity(), "trials": trials,
        "budget": asdict(budget) if budget else None,
    })
    client = RequestJournal(client, root / "requests.jsonl")
    phase = "development"
    try:
        with meta.Storage.durable(root / "history") as storage:
            try:
                result = meta.run(experiment(client, seed=seed, trials=trials), storage=storage, budget=budget)
                snapshot = show(result)
                selected = result.best().value if snapshot.rankability == "rankable" else None
            finally:
                run_ids = storage.runs()
                if len(run_ids) > 1:
                    raise meta.RunSelectionRequired(run_ids)
                if run_ids:
                    (root / "run-id.txt").write_text(run_ids[0].value + "\n", encoding="utf-8")
        print(snapshot)  # The captured report remains usable after storage closes.
        if selected is None:
            print("Separate final check: skipped; no successfully measured prompt.")
            return result.id
        (root / "selected.txt").write_text(selected, encoding="utf-8")
        from prompt_cases import FINAL

        phase = "final"
        final = evaluate(selected, client, cases=FINAL)
        save_json(root / "final.json", {
            "metrics": dict(final.metrics),
            "failure": ({"kind": final.failure.kind, "message": final.failure.message}
                        if final.failure else None),
            "evidence": [evidence_record(item) for item in final.evidence],
            "usage": asdict(final.usage),
        })
        print("Separate final check:", final.failure.kind if final.failure else
              f"{round(final.metrics['score'] * len(FINAL))}/{len(FINAL)}")
        print(f"Final tokens: {final.usage.tokens}; see final.json for separate usage and evidence.")
        return result.id
    except ExecutionAccountingUnknown as error:
        save_json(root / "accounting-unknown.json", {
            "phase": phase, "reason": str(error), "receipt": getattr(error, "receipt", None),
        })
        raise


def main():
    cli = argparse.ArgumentParser(description=__doc__)
    modes = cli.add_mutually_exclusive_group(required=True)
    modes.add_argument("--dry-run", action="store_true", help="preview policy and cases; no model calls")
    modes.add_argument("--run", type=Path, metavar="DIRECTORY", help="save a new experiment and final check")
    modes.add_argument("--inspect", type=Path, metavar="DIRECTORY", help="read saved results; no model calls")
    args = cli.parse_args()
    if args.dry_run:
        from openai_client import configuration

        print("Dry run: no SDK requests; accuracy is not measured.")
        print(POLICY)
        for ticket, expected in DEVELOPMENT[:6]:
            print(f"{ticket!r} -> {expected}")
        print("Maximum requests: 163 development + 12 final = 175 (no retries).")
        print("Configuration:", json.dumps(configuration(), sort_keys=True))
    elif args.inspect:
        identity = args.inspect / "run-id.txt"
        run_id = identity.read_text().strip() if identity.exists() else None
        try:
            with meta.open_run(args.inspect / "history", run_id=run_id) as result:
                snapshot = show(result)
        except meta.RunNotFound:
            if run_id is not None:
                raise  # A saved explicit identity must never fall back to another run.
            print("No committed run. No successfully measured prompt.")
        else:
            print(snapshot)
        for name in ("configuration.json", "final.json", "accounting-unknown.json"):
            path = args.inspect / name
            print(f"{name}:", path.read_text() if path.exists() else "not recorded")
    else:
        from openai_client import OpenAIClient

        try:
            with OpenAIClient.from_environment() as client:
                run_lesson(client, args.run)

    """Example-owned Responses integration with optional user-owned cost reporting."""

from dataclasses import dataclass, replace
from decimal import Decimal, ROUND_CEILING, localcontext
from importlib.metadata import version
import os
import time
from typing import Callable, Literal

import meta_evolve as meta
from meta_evolve.domain import InvalidOutput
from meta_evolve.errors import ExecutionAccountingUnknown

DEFAULT_MODEL = "gpt-5.4-mini-2026-03-17"


@dataclass(frozen=True)
class CostReport:
    usd: Decimal
    kind: Literal["estimated", "billed"]
    source: str

    def __post_init__(self):
        if not isinstance(self.usd, Decimal) or not self.usd.is_finite() or self.usd < 0:
            raise ValueError("usd must be a finite nonnegative Decimal")
        if self.kind not in ("estimated", "billed") or not isinstance(self.source, str) or not self.source.strip():
            raise ValueError("report an estimated or billed amount with its source")

    @property
    def micros(self):
        with localcontext() as context:
            context.prec = max(28, len(self.usd.as_tuple().digits) + 6)
            return int((self.usd * 1_000_000).to_integral_value(rounding=ROUND_CEILING))


CostReporter = Callable[[object], CostReport | None]


def configuration():
    return {
        "model": os.environ.get("OPENAI_MODEL", DEFAULT_MODEL),
        "endpoint": "https://api.openai.com/v1", "api": "responses",
        "timeout_seconds": 120, "max_retries": 0,
        "max_output_tokens": 4096, "reasoning_effort": "none",
        "store": False, "wrapper_revision": "2", "cost_reporter_id": None,
    }


def decode_response(response, *, elapsed, cost_reporter: CostReporter | None = None):
    """Keep provider tokens, optional billed spend, and labeled cost evidence.

    Run the callback once, including for incomplete responses. A failed cost
    lookup leaves spend unknown and records its error without losing the model
    result. Missing token accounting still raises rather than fabricating zero.
    """
    evidence = []
    spend = None
    if cost_reporter is not None:
        try:
            report = cost_reporter(response)
            if report is not None:
                if not isinstance(report, CostReport):
                    raise TypeError("cost_reporter must return CostReport or None")
                evidence.append(meta.EvidenceDraft(kind="cost-report", data={
                    "usd": str(report.usd), "micros": report.micros,
                    "kind": report.kind, "source": report.source,
                }))
                if report.kind == "billed":
                    spend = report.micros
        except Exception as error:
            evidence.append(meta.EvidenceDraft(kind="cost-reporting-failure", data={
                "exception_type": type(error).__name__,
                "message": "Cost reporter failed; billed spend remains unknown.",
            }))
    usage = getattr(response, "usage", None)
    input_tokens = getattr(usage, "input_tokens", None)
    output_tokens = getattr(usage, "output_tokens", None)
    if any(type(value) is not int or value < 0 for value in (input_tokens, output_tokens)):
        error = ExecutionAccountingUnknown("Response lacks required token accounting.")
        error.receipt = {
            "response_id": getattr(response, "id", None),
            "input_tokens": input_tokens, "output_tokens": output_tokens,
            "charged_micros": spend, "wall_seconds": elapsed,
            "cost_evidence": [dict(item.data) for item in evidence],
        }
        raise error
    measured = meta.Resources(
        tokens=input_tokens + output_tokens, spend_micros=spend, wall_seconds=elapsed,
    )
    text = getattr(response, "output_text", None)
    evidence.append(meta.EvidenceDraft(kind="openai-response", data={
        "response_id": response.id, "model": response.model,
        "status": response.status, "output_text": text,
        "input_tokens": input_tokens, "output_tokens": output_tokens,
        "charged_micros": spend,
    }))
    if response.status != "completed" or not isinstance(text, str) or not text.strip():
        return meta.ProposalResult(
            failure=InvalidOutput(message="model returned empty or incomplete text"),
            usage=measured, evidence=tuple(evidence),
        )
    return meta.ProposalResult(candidate=text, usage=measured, evidence=tuple(evidence))


@dataclass
class OpenAIClient:
    """The lesson knows generate() and configuration; SDK types stay here."""

    sdk: object
    configuration: dict
    cost_reporter: CostReporter | None = None

    def __post_init__(self):
        reporter_id = self.configuration.get("cost_reporter_id")
        if self.cost_reporter is not None and (
            not callable(self.cost_reporter) or not isinstance(reporter_id, str) or not reporter_id.strip()
        ):
            raise ValueError("a callable cost reporter needs a recorded cost_reporter_id")

    @classmethod
    def from_environment(cls, *, cost_reporter=None, cost_reporter_id=None):
        if not os.environ.get("OPENAI_API_KEY", "").strip():
            raise meta.CapabilityError("Set OPENAI_API_KEY before requesting a live run.")
        if cost_reporter is not None and (
            not callable(cost_reporter) or not isinstance(cost_reporter_id, str) or not cost_reporter_id.strip()
        ):
            raise ValueError("supply a callable cost_reporter and its cost_reporter_id")
        try:
            from openai import OpenAI
        except ImportError as error:
            raise meta.CapabilityError("Install the SDK: python -m pip install openai") from error
        settings = configuration() | {
            "sdk_version": version("openai"), "cost_reporter_id": cost_reporter_id,
        }
        sdk = OpenAI(api_key=os.environ["OPENAI_API_KEY"], base_url=settings["endpoint"],
                     timeout=settings["timeout_seconds"], max_retries=settings["max_retries"])
        return cls(sdk, settings, cost_reporter)

    def generate(self, *, instructions, input):
        settings = self.configuration
        started = time.monotonic()
        try:
            response = self.sdk.with_options(
                timeout=settings["timeout_seconds"], max_retries=settings["max_retries"],
            ).responses.create(
                model=settings["model"], instructions=instructions, input=input,
                max_output_tokens=settings["max_output_tokens"],
                reasoning={"effort": settings["reasoning_effort"]}, store=settings["store"],
            )
        except ExecutionAccountingUnknown:
            raise
        except Exception as cause:
            raise ExecutionAccountingUnknown(
                "Request failed after dispatch; token accounting is unavailable."
            ) from cause
        try:
            result = decode_response(response, elapsed=0, cost_reporter=self.cost_reporter)
        except ExecutionAccountingUnknown as error:
            error.receipt["wall_seconds"] = time.monotonic() - started
            raise
        # Include a cost lookup's elapsed time in the component's usage too.
        return replace(result, usage=replace(result.usage, wall_seconds=time.monotonic() - started))

    def __enter__(self):
        return self

    def __exit__(self, *exc):
        self.sdk.close()
