    Use your model SDK¶

    Improve support-ticket routing instructions with two Python functions: a proposer rewrites the prompt; an evaluator asks the model to label tickets and scores its answers. You own the SDK, model, and request settings.

    For a credential-free first run, use the parser lesson.

    You want to… Go to…
    Install and supply a key Configure
    Find the cell that sends requests Run
    Read scores, failures, and usage Inspect
    Apply this to your own idea Adapt the experiment

    Status: Experimental/live-only. The request cell makes at most three billable requests by default. Scores and usage vary; improvement is not promised.

    To run this page: copy cells in order, including the required accounting setup.

    1. Configure¶

    Use Python 3.12 or newer. Download the package ZIP into your notebook's working folder (%pwd); use the file browser to upload it in hosted notebooks. Install the official SDK alongside Meta-Evolve, then restart the kernel if asked.

    %pip install ./meta-evolve.zip "openai==2.54.0"

    The next cell reads OPENAI_API_KEY or asks for it through hidden input. You need a key with access to the model; credentials are not recorded.

    Request settings¶

    CLIENT_OPTIONS controls the SDK connection; REQUEST selects the model snapshot. The 512-token allowance bounds output per request, not total tokens or spend. The 120-second timeout is not a hard end-to-end deadline; there are no automatic retries. store=False disables Responses API storage; request/response text is retained locally.

    import os
import json
from getpass import getpass
from hashlib import sha256
from importlib.metadata import version
from openai import OpenAI
import meta_evolve as meta

CLIENT_OPTIONS = {
    "base_url": "https://api.openai.com/v1",
    "timeout": 120.0,
    "max_retries": 0,
}
REQUEST = {
    "model": "gpt-5.4-mini-2026-03-17",
    "max_output_tokens": 512,
    "reasoning": {"effort": "none"},
    "store": False,
}
client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY") or getpass("OpenAI API key: "),
    **CLIENT_OPTIONS,
)

    Expand and run this required setup before continuing. ask_model returns text or a typed failure with usage and evidence. Unknown spend stays None; missing required accounting interrupts execution. See the accounting reference.

    Required setup: request accounting 
    from time import perf_counter
from meta_evolve.domain import InvalidOutput
from meta_evolve.errors import ExecutionAccountingUnknown


def ask_model(instructions, text):
    started = perf_counter()
    try:
        response = client.responses.create(
            **REQUEST, instructions=instructions, input=text,
        )
        counts = (response.usage.input_tokens, response.usage.output_tokens)
        if any(type(count) is not int or count < 0 for count in counts):
            raise ValueError("Missing token accounting")
        output = response.output_text
        usage = meta.Resources(tokens=sum(counts), spend_micros=None,
                           wall_seconds=perf_counter() - started)
        evidence = (meta.EvidenceDraft(kind="sdk-response", data={
            "response_id": response.id,
            "model": response.model, "status": response.status,
            "instructions": instructions, "input": text, "output": output,
            "input_tokens": counts[0], "output_tokens": counts[1],
        }),)
    except Exception as error:
        raise ExecutionAccountingUnknown(
            "SDK request failed or its response lacks usable accounting."
        ) from error

    if response.status != "completed" or not output.strip():
        return meta.ProposalResult(
            failure=InvalidOutput(message="Model returned empty or incomplete text"),
            usage=usage, evidence=evidence,
        )
    return meta.ProposalResult(candidate=output, usage=usage, evidence=evidence)

    2. Supply your callables¶

    The seed is deliberately weak instruction text. SDK_POLICY tells the proposer what to improve; SDK_CASES holds six development tickets and independent answers.

    SDK_SEED = "Route every support ticket to technical."
SDK_POLICY = (
    "Route invoices and refunds to billing, passwords and login to account, "
    "and software problems to technical."
)
SDK_CASES = (
    ("Please send my invoice", "billing"),
    ("I need a refund", "billing"),
    ("I forgot my password", "account"),
    ("My login is blocked", "account"),
    ("The dashboard freezes", "technical"),
    ("Export is broken", "technical"),
)

    The proposer uses one evaluator-owned report for the current prompt. Disabled context raises ContextDisabled; missing or mismatched feedback stops before dispatch.

    def propose_sdk(prompt, *, context):
    report = context.evidence.latest("routing-checks")
    if report is None:
        raise meta.CapabilityError("No routing checks selected; check max_records.")
    if report.data.get("prompt_sha256") != sha256(prompt.encode()).hexdigest():
        raise meta.CapabilityError("Feedback is for another prompt; check the policy.")
    if context.evidence.truncated:
        print("Feedback: selected report retained; context records or text truncated.")
    return ask_model(
        "Rewrite the ticket-routing instructions to follow this policy: "
        + SDK_POLICY + " Return only the revised instructions.",
        json.dumps({"prompt": prompt, "development": report.data}, default=dict),
    )

    The evaluator labels six tickets in one request and grades against independent answers. It alone writes routing-checks; a label is not proof of authorship. The prompt digest checks content, while the accessor retains the source occurrence.

    def evaluate_sdk(prompt):
    reply = ask_model(
        prompt + "\nReturn one lowercase label per ticket, one per line, "
        "in input order. No numbering or explanation.",
        "\n".join(ticket for ticket, _ in SDK_CASES),
    )
    labels = reply.candidate.strip().splitlines() if reply.failure is None else []
    valid_count = len(labels) == len(SDK_CASES)
    checks = [{
        "ticket": ticket, "expected": expected,
        "actual": labels[index].strip() if index < len(labels) else None,
        "passed": valid_count and labels[index].strip() == expected,
    } for index, (ticket, expected) in enumerate(SDK_CASES)] if reply.failure is None else []
    return meta.EvaluationResult(
        metrics={"score": sum(check["passed"] for check in checks) / len(SDK_CASES)}
                if reply.failure is None else {},
        failure=reply.failure, usage=reply.usage,
        evidence=reply.evidence + (meta.EvidenceDraft(
            kind="routing-checks", data={
                "prompt_sha256": sha256(prompt.encode()).hexdigest(),
                "valid_count": valid_count, "checks": checks,
                "complete": reply.failure is None,
                "failure": reply.failure.kind if reply.failure else None,
            },
        ),),
    )

    Why can a wrong answer have a score? A completed response with wrong labels is a measured mistake; the wrong number of labels fails every check. Empty or incomplete responses are typed failures with no score, retaining known usage.

    3. Run one improvement attempt¶

    Task records SDK configuration and maximizes score; Experiment adds search and authorized feedback. Keep this expanded path when recording an environment; improve() suits simpler declarations.

    sdk_experiment = meta.Experiment(
    seed=SDK_SEED,
    proposer=propose_sdk,
    task=meta.Task(evaluator=evaluate_sdk, environment={
        "sdk_version": version("openai"), "request": REQUEST,
        "client_options": CLIENT_OPTIONS,
    }),
    search=meta.Greedy(max_trials=1),
    context=meta.RecentAncestors(max_records=40, max_chars=16_000),
)

    This cell sends the requests: seed evaluation → rewrite → revision evaluation, at most three requests. A failed rewrite skips revision evaluation. Rerunning meta.run() starts another paid experiment; inspection sends nothing.

    sdk_result = meta.run(sdk_experiment)

    4. Inspect results¶

    Inspect attempts and checks, then capture a snapshot. Proposals exclude the seed; evaluations include it. A captured summary survives storage closure; new queries need open storage. This default run is in memory, so history is not saved durably.

    for number, attempt in enumerate(sdk_result.trials()):
    outcome = (attempt.failure.kind if attempt.failure
               else f"{attempt.metrics['score']:.0%}")
    print(f"Version {number}: {outcome}")
best = sdk_result.inspect().overview.best_trial
if best is not None:
    print("Selected prompt:", sdk_result.best().value)
    for item in best.evidence:
        if item.kind == "routing-checks":
            for check in item.data["checks"]:
                print(check["ticket"], "->", check["actual"],
                      "expected", check["expected"])
sdk_snapshot = sdk_result.summary()
print(sdk_snapshot)

    The seed may stay best; all-failed runs have no selected prompt. Tokens include input and output without double-counting cached input. Unknown spend is not free.

    For ExecutionAccountingUnknown, inspect the underlying SDK error before retrying; see failure accounting.

    Development scores do not establish unseen-ticket performance or repeatability.

    Change and predict¶

    Set max_trials=0 in the declaration, rerun it and the request cell, then inspect. Predict the count: at most one request, zero proposals, and one evaluation if it completes.
